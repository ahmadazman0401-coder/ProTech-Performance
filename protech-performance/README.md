# ProTech Performance — Melaka

A responsive one-page website built with plain HTML, CSS and JavaScript. It is ready for GitHub Pages and does not require a build step.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Updating business details

The address, WhatsApp number and social links are in `index.html`. The colour system and layout are in `styles.css`.

## Included

- Responsive desktop and mobile layouts
- Mobile navigation
- Service enquiry shortcuts
- WhatsApp quote form (no backend required)
- Scroll reveal motion with reduced-motion support
- SEO and social sharing metadata
